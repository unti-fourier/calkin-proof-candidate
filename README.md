## 問題と証明を目指す主張

可分無限次元 Hilbert 空間 $`H=\ell^2(\mathbb N)`$ を固定し、その Calkin 代数を

$$
Q=\mathcal B(H)/\mathcal K(H)
$$

とします。任意の複素 $`C^*`$ 代数 $`B`$ に対し、代数的テンソル積上の恒等写像から定まる標準的な全射 $`*`$ 準同型

$$
\chi_B:B\otimes_{\max}Q\longrightarrow B\otimes_{\min}Q
$$

を考えます。本稿で証明を目指す主張は

$$
\chi_B\text{ が単射}\quad\Longleftrightarrow\quad B\text{ が核的}
$$

です。$`B`$ の単位性・可分性・sigma-unitality・事前の exactness は仮定しません。単射性は**完備化されたテンソル積の間**での主張であり、指定された代数的テンソル積上の max/min ノルム一致と同値です。

核性から単射性への向きは定義から従います。本稿では逆向きの証明を提案します。仮説から元の $`B`$ の exactness を得た後、非核性を仮定して矛盾を導く構成です。

This work proposes a proof of the fixed Calkin tensor test: for an arbitrary complex C*-algebra $`B`$, the canonical map $`B\otimes_{\max}Q\to B\otimes_{\min}Q`$, with $`Q=\mathcal B(\ell^2)/\mathcal K(\ell^2)`$, is injective if and only if $`B`$ is nuclear. No unitality, separability, or initial exactness of $`B`$ is assumed. The candidate combines a bidual-corner input, a cyclic-lamp cocycle estimate, one completely positive moment map, and an exactness cut preserving a fixed state. Related topics include nuclearity, exactness, and the local lifting property (LLP). The full argument is available through the manuscript link above.
